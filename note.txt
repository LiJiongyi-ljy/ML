=================================================
with...as


try:
    f = open("hello.txt", "w")
    f.write("Hello!")
finally:
    f.close()

with即把这种模式封装起来
with open("hello.txt", "w") as f:
    f.write("Hello!")


as f 的意思就是：
把 with 管理的那个对象，起个名字叫 f


```python

class ManagedFile:
    def __init__(self, name, mode):
        self.name = name
        self.mode = mode

    def __enter__(self):
        self.f = open(self.name, self.mode)
        return self.f		#__enter__() 的返回值，会赋给 as 后面的变量

    def __exit__(self, exc_type, exc_val, exc_tb):
        self.f.close()
```

=================================================
Context Manager
	
只要一个对象提供了：

__enter__()
__exit__()

它就可以作为：

Context Manager（上下文管理器）

使用：

with xxx:
    ...

它不只可以管理文件,还可以管理：

文件
数据库连接
网络连接
锁
线程资源
临时资源
事务

例如：

with lock:
    # 操作共享数据

意思就是：进入 → 获得锁	执行代码	    退出 → 释放锁
